SMARTNEST - Smart App Store

Benodigd:
- Python 3
- Internetverbinding voor het actuele weer

Starten:
1. Open de projectmap in PyCharm.
2. Voer main.py uit.
3. Kies een applicatie in het hoofdmenu.

Bestanden:
- main.py: centraal menu en Open-Meteo API
- weerstation.py: weersberekeningen en rapportage
- smart_app_controller.py: berekening en overschrijven van actuatoren
- weerdata.txt: invoergegevens voor de controller
- actuatoren.txt: wordt gegenereerd door de controller

Gebruik van AI:
AI is gebruikt als hulpmiddel bij het opzetten en controleren
van de programmastructuur en bij het oplossen van programmeerfouten.
